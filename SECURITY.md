# 🔒 Política de Seguridad

## Reportar Vulnerabilidades

Si descubres una vulnerabilidad de seguridad, **no la publiques en GitHub Issues**.

Por favor, envía un email confidencial a:
```
seguridad@generadoraudio.dev
```

O usa el Security Advisory en GitHub:
1. Ve a **Security** > **Report a vulnerability**
2. Completa el formulario
3. Describe la vulnerabilidad con detalles técnicos

## Información que incluir

- Descripción del problema
- Pasos para reproducir
- Impacto potencial
- Sugerencias de corrección (opcional)

## Política de Divulgación

- Trabajaremos contigo para resolver el problema
- Objetivo: parcha en 30 días
- Reconocimiento público en release notes (si deseas)
- Reporte del CVE si es aplicable

## Medidas de Seguridad Implementadas

### Android
✅ **ProGuard Obfuscation** - Ofuscación de código
✅ **SSL Pinning** - Prevenir MITM attacks
✅ **Permisos Mínimos** - Solo permisos necesarios
✅ **Data Encryption** - Datos sensibles encriptados
✅ **HSTS** - HTTP Strict Transport Security

### Windows
✅ **Code Signing** - Ejecutable firmado
✅ **UAC Manifest** - Control de acceso de usuario
✅ **ASLR** - Address Space Layout Randomization
✅ **DEP** - Data Execution Prevention
✅ **AntiTamper** - Detección de modificaciones

### General
✅ **HTTPS** - Comunicación encriptada
✅ **Dependency Scanning** - Revisión de dependencias
✅ **SAST** - Static Application Security Testing
✅ **Penetration Testing** - Testing de seguridad
✅ **Security Headers** - Headers de seguridad HTTP
