# CHANGELOG

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2024-08-27

### Agregado
- ✅ Aplicación Android con Kotlin + MVVM
  - Síntesis de voz (TTS) nativa
  - Generación de archivos MP3
  - Control de velocidad y voz
  - Interfaz Material Design 3
  - Compartir archivos de audio

- ✅ Aplicación Windows con C# + WPF
  - Interfaz moderna y responsiva
  - SAPI5 para síntesis de voz
  - Control de volumen y tono
  - Soporte multiidioma
  - Exportación a MP3 con NAudio
  - Preescucha en tiempo real

- ✅ Herramientas de compilación y distribución
  - Instalador MSI para Windows
  - Firma de APK para Google Play
  - CI/CD con GitHub Actions
  - Temas Material Design 3
  - Sistema de versionado automático

- ✅ Documentación completa
  - Guía de uso
  - Instrucciones de compilación
  - Guía de publicación en Google Play
  - Configuración de instalador

### Seguridad
- ProGuard obfuscation para Android
- Permisos mínimos requeridos
- Validación de entrada en ambas plataformas
