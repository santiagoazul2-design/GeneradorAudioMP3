# 🚀 Guía Rápida de Inicio

## ¿Quieres generar audio desde tu PC o teléfono?

### 💻 Windows
1. **Descargar** installer desde GitHub Releases
2. **Ejecutar** GeneradorAudioMP3.msi
3. **Abrir** desde Menú Inicio o Escritorio
4. **Escribir** texto y presionar **Generar MP3**

### 📱 Android
1. **Descargar** APK desde GitHub Releases
2. **Instalar** en tu dispositivo
3. **Abrir** la app
4. **Escribir** texto y presionar **Generar MP3**
5. **Compartir** o guardar el archivo

## ⚙️ Configuración Recomendada

### Para voz clara
- Velocidad: **Normal**
- Voz: **Femenina** (más inteligible)
- Volumen: **100%**

### Para voz dramática
- Velocidad: **Lenta**
- Voz: **Masculina**
- Tono: **Grave** (Windows)

### Para publicidad comercial
- Velocidad: **Comercial**
- Voz: Cualquiera
- Volumen: **100%**
- Tono: **Normal** (Windows)

## 🆘 Solución de problemas

**¿No genera audio?**
- Verifica que haya suficiente espacio en disco
- Revisa los permisos de almacenamiento

**¿Audio con mala calidad?**
- Aumenta volumen a 100%
- Usa velocidad "Normal"

**¿La app se congela?**
- Reduce la cantidad de caracteres
- Reinicia la aplicación
